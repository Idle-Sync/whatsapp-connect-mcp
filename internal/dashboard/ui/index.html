Link this server to WhatsApp

This server is linked to your WhatsApp. Unlinking signs it out on WhatsApp's servers — the same as removing it from Linked devices on your phone — and brings the QR code back to pair again.

Pairing shows a QR code here. Scan it from WhatsApp > Linked devices > Link a device.

MCP clients

Apps on this machine that can talk to this server. Adding one writes a whatsapp entry into that app's MCP config — restart the app afterwards for it to pick the entry up.

    Readable chats

    Limit what any connected agent can read. With nothing listed here every chat is readable. Add a chat and the list becomes an allowlist: everything outside it is invisible to an agent — messages, search results, contacts and calls alike. This page and the CLI are the only places it can be changed; no agent can widen its own scope.

      Trusted contacts

      Trusted contacts auto-send without a draft preview. Add only people you'd let an agent message directly.
